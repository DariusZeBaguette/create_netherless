# Create: Netherless, now open-source!
This mod is a small add-on to the [Create Mod](https://www.curseforge.com/minecraft/mc-mods/create) that is currently __supporting__ for Forge 1.20.1 and Neoforged 1.21.1.
Its main goal is to provide players with the possibility of __making and automating most Nether resources__ even without access to the Nether! This includes Blazes, Netherite, Netherrack, or anything else you can think of that is locked behind the Nether.

⚠️Through updates, recipes might __change__ or get __deleted__, so please **read changelogs** before updating!
